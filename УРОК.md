# УРОК: как устроен «Дизель Монітор UA»

Урок для владельца проекта. Все факты взяты из кода и из истории git на 06.10.2026.
Где есть сомнение, это сказано прямо.
Важное уточнение. В задании проект назван «сборщики цен на Python». В репозитории нет файлов на Python.
Все сборщики написаны на JavaScript для Node.js, файлы `.mjs`. Синтаксис близок к Python:
функции, условия, циклы, словари (в JS это объекты) и списки (массивы).

---
## 1. Что делает проект

«Дизель Монітор UA» — сайт с ценами на топливо в Украине: https://diesel-monitor.pp.ua/.
Робот два раза в день читает цены с сайта Минфина, курс доллара с сайта НБУ и цену нефти Brent с Yahoo.
Он чистит эти числа, сверяет источники между собой и дописывает их в файлы JSON.
Из этих файлов собирается сайт на GitHub Pages. Из них же робот делает посты в Telegram и Instagram.
Сервера нет. Всё крутится в GitHub Actions по расписанию. Ноутбук владельца не нужен.
Проект для водителей, которые хотят знать цену дизеля сегодня и где дешевле. Второй читатель — сам владелец.

## 2. Карта файлов

### Корень

- `README.md` — краткое описание проекта, источники данных, команды запуска.
- `DESIGN.md` — правила внешнего вида сайта: цвета, шрифт, карточки, типы данных.
- `package.json` — список библиотек и команды `npm run dev`, `build`, `lint`, `collect`, `backfill`.
- `index.html` — оболочка сайта и SEO-теги. Описание в ней подменяет `scripts/seo.mjs` при сборке.
- `package-lock.json`, `vite.config.ts`, `tsconfig*.json`, `.oxlintrc.json`, `.prettierrc` — настройки. Читать не нужно.
- `.gitignore` — что не попадает в git: `node_modules`, `dist`, `frames/`, `.env`.
- `.gitattributes` — правило: файлы в `scripts/` всегда с концами строк LF. Внутри подробно объяснено, зачем.

### `scripts/` — сборщики и публикаторы (Node.js)

- `collect.mjs` — главный сборщик: цены, курсы, Brent, новости. Пишет `public/data/*.json`.
- `backfill.mjs` — разовая заливка истории с 2024 года из Wayback Machine. Запускают редко.
- `ev-collect.mjs` — зарядки электромобилей из OpenStreetMap. Раз в неделю.
- `змінилось.mjs` — отвечает «да» или «нет»: изменилось ли в данных что-то, кроме меток времени.
- `виправити-зсув-історії.mjs` — одноразовый ремонт истории за 11–21.09.2026. Уже применён.
- `seo.mjs` — вписывает цену дня в description перед сборкой сайта.
- `prerender.mjs` — делает 311 статических HTML-страниц и sitemap после сборки.
- `price-card.mjs` — рисует PNG-карточку цен для Telegram.
- `telegram-post.mjs` — пост цен в Telegram-канал после сбора.
- `telegram-news.mjs` — одна новость в Telegram за запуск, не больше 4 в сутки.
- `instagram-carousel.mjs` — карусель из 5 слайдов в Instagram.
- `instagram-news.mjs` — карточка новости или «где дешевле» в Instagram.
- `instagram-story.mjs` — сторис с ценами.
- `reel-check.mjs`, `reel-frames.mjs`, `reel-music.mjs`, `reel-voice.mjs`, `reel-compose.mjs`, `instagram-reel.mjs` — конвейер Reels.
- `ig-insights.mjs` — недельная сводка по Instagram владельцу в Telegram.
- `ig-bridge.mjs` — мост комментариев Instagram ↔ Telegram. Расписание выключено.
- `tests-*.mjs` — пробы (тесты). Пять наборов плюс «подсадки» в `tests-mutations.mjs`.
- `og.mjs`, `favicon.mjs`, `fixtures/` — разовые картинки и образец данных для пробы. Читать не нужно.

### `scripts/lib/` — общие модули

- `minfin.mjs` — разбор страниц Минфина. Самый большой файл, 1028 строк.
- `числа.mjs` — проверка курсов и Brent: границы, код валюты, скачок за сутки.
- `звірка.mjs` — сверка источников цен между собой и выбросы отдельных сетей.
- `мережі.mjs` — решение: брать свежую карту сетей или оставить прошлую.
- `значуще.mjs` — какие поля в JSON «летучие» и не считаются изменением.
- `networks-fresh.mjs` — свежая ли карта сетей и можно ли писать «сьогодні».
- `news.mjs` — RSS-ленты, фильтр по теме, перевод, оценка влияния новости.
- `hashtags.mjs` — хэштеги и «крайняя» область для подписей.
- `зсув-історії.mjs` — логика ремонта сдвинутых дней истории.

- `main.tsx` — точка входа. Оборачивает приложение в роутер и поставщик данных.

- `components/`, `pages/` — панели (график, сети, области, новости) и четыре страницы.

### `public/` — то, что лежит на сайте как есть

## 3. Путь данных от входа к выходу

### Схема

```
Минфин (4 страницы)  НБУ (USD, EUR)  Yahoo (Brent)  RSS (10 лент)
        |                  |              |              |
        v                  v              v              v
              scripts/collect.mjs  (раз в день в 12:10 и 18:10 UTC)
                    |
                    |-- разбор:   lib/minfin.mjs, lib/news.mjs
                    |-- проверка: lib/числа.mjs  (границы, код валюты, скачок)
                    |-- сверка:   lib/звірка.mjs (источники друг против друга)
                    |-- выбор:    lib/мережі.mjs (свежая карта сетей или прошлая)
                    v
        public/data/latest.json   history.json   factors.json   news.json   collect-log.json
                    |  git commit + git push в main (делает бот diesel-monitor-bot)
                    v
     +--------------+---------------------------+----------------------------+
     v                                          v                            v
  deploy (та же задача collect.yml)      telegram-post.mjs            workflow_run:
  seo.mjs -> npm run build ->            (карточка + текст)           instagram.yml (карусель)
  prerender.mjs -> GitHub Pages                                       ig-story.yml (сторис)
     v
  https://diesel-monitor.pp.ua  (сайт читает те же JSON через src/api/provider.ts)
```

### Откуда берутся цены

Сборщик читает четыре страницы Минфина. Адреса записаны в начале `collect.mjs`.
- `/ua/markets/fuel/` — средние цены по стране и изменение за день.
- `/ua/markets/fuel/tm/` — цены по 36 сетям АЗС.
- `/ua/markets/fuel/reg/` — средние цены по 23 областям.
- `/ua/markets/fuel/detail/` — матрица «область × сеть». Минфин убирал её 29.07.2026 и вернул в сентябре.
Страницы отдаются в кодировке windows-1251. Функция `fetchPage` в `lib/minfin.mjs` сама определяет кодировку.
Курс доллара и евро берётся из API НБУ. Brent — из Yahoo Finance по символу `BZ=F`.
Новости — из 4 украинских и 6 мировых RSS-лент. Мировые переводятся на украинский бесплатным переводчиком Google.

### Как чистятся

Каждый источник необязателен. Если одна страница сломалась, сбор продолжается на остальных.
Это делает обёртка `tryParse` в `collect.mjs`. Раньше одна сломанная страница валила весь сбор.

Числа проходят проверки из `lib/числа.mjs`:

- курс берётся по коду валюты, а не из первой строки ответа;
- USD должен быть от 20 до 150, EUR от 20 до 180, Brent от 10 до 300;
- отношение EUR к USD должно быть от 0,8 до 1,7;
- скачок больше 30% за сутки не публикуется.

Дата данных берётся со страницы Минфина, а не с календаря. Самая свежая дата побеждает.
Страница со старой датой снимается с тревогой. Тревога идёт в журнал и жёлтой пометкой в GitHub Actions.
Потом `lib/звірка.mjs` сравнивает источники. Каждый источник даёт по одному числу на вид топлива.
Источник, который разошёлся с большинством больше чем на 8%, снимается целиком.
Отдельная сеть с ценой, далёкой от медианы больше чем на 50%, теряет только эту цену.

Все данные в `public/data/`. Числа ниже — из файлов на 06.10.2026.

| `history.json` | одна точка на день с 2024 года | 267 дней, первый 2024-01-02 |

### Как попадают на сайт

Бот коммитит `public/data` в `main`. Потом `scripts/змінилось.mjs` решает, нужен ли деплой.
Если поменялись только метки времени, сайт не пересобирается. Если поменялась цена, запускается задача `deploy`.
Она запускает `seo.mjs`, потом `npm run build`. Сборка делает `tsc`, `vite build` и `prerender.mjs`.
Пререндер создаёт 311 HTML-страниц: 23 области, 36 сетей, 245 пар «топливо × область/сеть», 4 «где дешевле».
Готовая папка `dist/` выкладывается на GitHub Pages. Сайт в браузере сам читает те же JSON.

### Как попадают в Instagram и Telegram

Telegram-пост цен идёт прямо в `collect.yml` после коммита данных. Падение поста не ломает сбор.
Instagram ждёт события `workflow_run`: «сбор цен завершён». Так пост не выходит раньше данных.
Скрипт рисует SVG, делает из него JPG библиотекой `sharp` и коммитит файл в `public/cards/`.
Потом он отдаёт Instagram ссылку на этот файл в GitHub. Instagram сам его скачивает и публикует.
Reels собираются из кадров PNG, видеофона, музыки CC0 и голоса диктора. Склейка — программой ffmpeg.

## 4. Расписания и автоматика

Все workflow лежат в `.github/workflows/`. Время в cron указано в UTC. Киев — UTC+2 или UTC+3.
GitHub запускает cron с опозданием на 1–5 часов. Так говорят комментарии в workflow и отчёт аудита.

| Файл | Когда | Что делает |
|---|---|---|
| `collect.yml` | `10 12,18 * * *` и вручную | сбор цен, коммит, пост в Telegram, деплой если есть изменение |
| `news.yml` | `37 */3 * * *` | только новости (`collect.mjs --news-only`), коммит, деплой при изменении |
| `tg-post.yml` | `47 */4 * * *` | одна новость в Telegram-канал, не больше 4 в сутки |
| `deploy.yml` | push в `main` и вручную | сборка сайта и выкладка на Pages |
| `ev.yml` | `20 3 * * 1` (понедельник) | зарядки EV из OpenStreetMap |
| `instagram.yml` | после `collect.yml` (`workflow_run`) | карусель цен из 5 слайдов |
| `ig-story.yml` | после `collect.yml` | сторис с ценами |
| `ig-news.yml` | `0 16 * * *` | карточка новости или «где дешевле» |
| `reels.yml` | `30 5 * * *` | проверка повода; видео только при движении цены или по длинному окну |
| `ig-insights.yml` | `0 6 * * 1` | недельная сводка владельцу в Telegram |
| `ig-refresh.yml` | `0 5 1 * *` (1-е число) | продление токена Instagram и перезапись секрета |
| `ig-bridge.yml` | только вручную | мост комментариев; cron выключен 22.08.2026 |
| `notify.yml` | только вручную | отправить владельцу текст или видео в Telegram |

Важные детали:

- Пуш от встроенного `GITHUB_TOKEN` не запускает `deploy.yml`. Поэтому деплой встроен в `collect.yml`, `news.yml`, `ev.yml`.
- Группы `concurrency`: `collect` для всех, кто пушит данные, `instagram` для всех постов. Два запуска группы не идут разом.
- Права выданы по задачам. Сбор имеет только `contents: write`. Деплой — `pages: write` и `id-token: write`.

Где смотреть журнал:

- GitHub → вкладка **Actions** → нужный workflow → последний запуск → шаг. Тревоги сбора видны жёлтым в сводке.
- `public/data/collect-log.json` — последние 100 запусков. Поле `ok` показывает, что удалось. Поле `тривоги` — что сняли.
- Коммиты бота в `main` с префиксом `data:`, `ig:`, `story:`, `reel:` — след каждого запуска. Таких коммитов 1524 из 1660.

## 5. Ключи и секреты

Значения тут не приводятся. Файлы `.env` не читались. В коде зашитых ключей нет; это подтверждает `tests-security.mjs`.

Секреты GitHub (Settings → Secrets and variables → Actions → **Secrets**):

- `INSTAGRAM_TOKEN` — токен Instagram. Живёт 60 дней, продлевается `ig-refresh.yml`.
- `TELEGRAM_BOT_TOKEN` — токен бота Telegram.
- `GEMINI_API_KEY` — ключ Gemini для озвучки Reels. Передаётся в заголовке, не в адресе.
- `GH_PAT` — личный токен GitHub с правом «Secrets: read and write». Нужен только `ig-refresh.yml`.

Переменные GitHub (там же, вкладка **Variables**, не секреты):

- `TELEGRAM_CHANNEL` — имя канала вида `@diesel_monitor_ua`.
- `TG_OWNER_CHAT` — chat_id владельца для служебных сообщений.

На ноутбуке скрипты читают те же имена из `process.env`. Загрузчика `.env` в коде нет: переменную задают в оболочке.
`.env` и `.env.*` стоят в `.gitignore`. Без токенов публикаторы печатают «пропускаю» и выходят. Сбор цен ключей не требует.
Необязательные переменные: `IG_FORCE`, `TG_FORCE` (принудительный пост), `REEL_BG` (фон Reels),
`TG_NEWS_MAX`, `TG_NEWS_MAX_DAY`, `TG_NEWS_FRESH_HOURS` (лимиты новостей), `FFMPEG` (путь к ffmpeg).

## 6. Как запустить у себя

Нужен Node.js 22. Workflow используют версию 22. Проверка: `node --version`.

```bash
git clone https://github.com/Ros-ua/diesel-monitor
cd diesel-monitor
npm ci                 # ставит библиотеки точно по package-lock.json
npm run dev            # сайт на http://localhost:5173, данные из public/data
npm run build          # tsc + vite + prerender; в конце ждите строку
                       # «prerender: 311 сторінок (23 областей, 36 мереж) + sitemap»
npm run lint           # oxlint; сейчас 0 ошибок и 14 предупреждений
npx tsc -b             # проверка типов; тишина = успех
```

Пробы. Они не запускаются автоматически ни в Actions, ни через `npm test`. Запускайте руками:

```bash
node scripts/tests-parser.mjs     # разбор страниц и чисел; ждите 229 ✅ и «усі проби пройшли»
node scripts/tests-collect.mjs    # настоящий collect.mjs с подменённой сетью; ждите 78 ✅
node scripts/tests-front.mjs      # даты осей, «Вчора»; ждите 34 ✅
node scripts/tests-geo.mjs        # SEO-разметка; ждите «GEO: 100 з 100»
node scripts/tests-security.mjs   # права workflow; нужен python3 с PyYAML; ждите 43 ✅
node scripts/tests-mutations.mjs  # подсадки, около 3 минут; каждая должна краснить свою пробу
node scripts/змінилось.mjs        # без сети: «ні: змінились лише позначки часу», код выхода 1
node scripts/reel-check.mjs       # без сети: «⏸ пропускаємо: …» или «✅ знімаємо Reels: …»
```

Настоящий сбор: `npm run collect`. Он ходит на Минфин, НБУ, Yahoo и в RSS и перезаписывает `public/data`.
Коммитить результат руками не нужно: бот делает это сам. Вернуть данные: `git checkout public/data`.

Картинки без публикации: `node scripts/instagram-carousel.mjs --cards` и `node scripts/instagram-story.mjs --card`.
Какие числа ждать в данных: откройте `public/data/latest.json`. Поле `avg.dp` — около 98 грн на начало октября 2026.
Поле `networks` — 36 ключей. Поле `regionAvg` — 23 ключа. Поля `usd` около 45, `eur` около 50, `brent` около 100.

## 7. Что ломалось раньше и как починили

Случаи взяты из `git log` и из `docs/ОТЧЁТ_ОБЛАКО.md`. Коммит указан первыми 7 знаками.

**1. Сбор падал из-за поста в Telegram — `a6ec75b`, 25.07.2026.**
Workflow не делал `npm ci`, библиотеки `sharp` не было, скрипт карточки падал. Падение блокировало коммит данных.
Сайт застрял на ценах 23.07. Починили: добавили `npm ci`, данные коммитятся первыми, пост идёт с `continue-on-error`.

**2. Instagram публиковал вчерашние цены — `05582b5`, 27.07.2026.**
Пост шёл по своему cron в 13:00. GitHub задерживал сбор на 1–2 часа, и пост выходил раньше данных.
Починили: пост запускается событием `workflow_run` после сбора и берёт свежий `main`.

**3. Минфин разделил страницу — `a801201`, 30.07.2026.**
29.07 страница `/detail/` разделилась на `/tm/` (сети) и `/reg/` (области). Сбор перестал видеть сети.
Починили: два новых парсера. Колонки выравниваются с конца строки, потому что в `/tm/` есть лишняя ячейка с логотипом.

**4. Мост съел лимит Instagram, карусель вышла дважды — `d5060ed` и `b4d0743`, 22.08.2026.**
Мост опрашивал Instagram каждые 15 минут, около 1700 запросов в сутки. Meta заблокировала публикации.
При этом API ответил ошибкой, а пост создал. Скрипт не записал состояние и опубликовал повтор.
Починили: cron моста выключен; карусель после ошибки ждёт 5 секунд и проверяет аккаунт.

**5. Дата ловилась внутри слова и затирала историю — `a72fa0d`, 12.09.2026.**
Регулярное выражение искало «на» без границы слова и находило его внутри «ціна». Бралась дата архива 28.07.
Сегодняшние цены записывались под 28.07 и затирали тот день. Починили: сначала явные слова «оновлення», потом
«на» как отдельное слово, и дата должна быть не из будущего и не старше недели. Появились первые пробы.

**6. На сайте стояли «EUR 0,00» и «Brent $-80» — `f320266`, 12.09.2026.**
Пустая строка от НБУ превращалась в ноль. Отрицательная нефть от Yahoo проходила. Журнал писал «успех».
Починили: вынесли проверки в `lib/числа.mjs`. Число должно быть конечным и в границах. Флаги журнала — по результату проверки.

**7. Сайт пересобирался дважды в день без причины — `e6f6bc9`, 12.09.2026.**
В каждом файле есть метка времени, и `git diff` всегда видел изменение. Деплой шёл даже при тех же ценах.
Починили: `змінилось.mjs` сравнивает файлы без «летучих» полей. Список полей в `lib/значуще.mjs`.

**8. Семь дней истории со сдвинутыми колонками — `ee17d70` 26.09 и `7a494e8` 27.09.2026.**
С 11 по 21.09 цены сетей легли со сдвигом: дизель записан как А-92, под «газом» стоял дизель. Парсер был уверен.
Починили в два шага. Сначала `lib/звірка.mjs`: источники сверяются друг с другом, расхождение больше 8% снимает источник.
Потом `виправити-зсув-історії.mjs` вернул 7 дней на место. Газ сетей за эти дни потерян: его в таблице не было.

## 8. Как читать код: три разбора

### 8.1. `курсНБУ` — `scripts/lib/числа.mjs`, строка 59

```js
export function курсНБУ(json, код) {
  if (!Array.isArray(json)) return null;
  const рядок = json.find(р => String(р?.cc ?? '').toUpperCase() === код);
  if (!рядок) return null;
  return курс(рядок.rate, МЕЖІ[код.toLowerCase()]);
}
```

- Строка 1. Функция принимает ответ НБУ `json` и код валюты, например `'USD'`. `export` открывает её другим файлам.
- Строка 2. Если ответ не список, возвращаем `null`. `null` значит «числа нет». Это не ноль.
- Строка 3. Ищем строку, у которой поле `cc` равно коду. `р?.cc` не падает на пустом `р`, `?? ''` даёт пустую строку.
  `find` похож на `next(x for x in json if ...)` в Python.
- Строка 4. Строки с нужной валютой нет — возвращаем `null`.
- Строка 5. Отдаём курс через функцию `курс`. Она проверяет границы из словаря `МЕЖІ`. Для USD это 20..150.

Зачем: раньше код брал `json[0].rate`. Полный список валют НБУ начинается с AUD около 27 грн. Он ушёл бы как доллар.

### 8.2. `вибратиМережі` — `scripts/lib/мережі.mjs`, строка 33

```js
export function вибратиМережі({ свіжі, попередні, дата, попередняДата = null }) {
  const було = попередні ? Object.keys(попередні).length : 0;
  const стало = свіжі ? Object.keys(свіжі).length : 0;
  const обвал = було >= МІНІМУМ_ДЛЯ_ПОРІВНЯННЯ && стало > 0 && стало * 2 < було;
  const взяти = свіжі && !обвал ? свіжі : null;
  return {
    мережі: взяти ?? попередні ?? null,
    свіжі: !!взяти,
    обвал, було, стало,
    дата: взяти ? дата : попередняДата,
  };
}
```

- Строка 1. Функция берёт один объект с четырьмя полями, как именованные аргументы в Python. `= null` — значение по умолчанию.
- Строки 2–3. Считаем сети в прошлой и в свежей карте. `Object.keys(x).length` это `len(x)` для словаря.
- Строка 4. Обвал — это когда было хотя бы 4 сети, сейчас больше нуля, и стало меньше половины.
  Так 36 → 35 проходит спокойно, а 36 → 1 считается поломкой вёрстки.
- Строка 5. Берём свежую карту, если она есть и обвала нет. Иначе `null`.
- Строки 6–11. Возвращаем решение. `??` берёт первое непустое: свежая, иначе прошлая, иначе `null`.
  `!!взяти` превращает значение в `true` или `false`. Дата — дата свежего сбора или дата прошлой карты.

Зачем: раньше одна уцелевшая сеть заменяла всю карту, и прошлая карта ложилась под сегодняшней датой.
Функция чистая: не ходит в сеть и не читает файлы. Поэтому её легко проверить пробой.

### 8.3. `значущеЗмінилось` — `scripts/lib/значуще.mjs`, строка 42

```js
export function значущеЗмінилось(старий, новий, летючі = []) {
  if (новий === null) return false;
  if (старий === null) return true;
  let а;
  let б;
  try {
    а = JSON.parse(старий);
    б = JSON.parse(новий);
  } catch {
    return старий !== новий;
  }
  return JSON.stringify(без(а, летючі)) !== JSON.stringify(без(б, летючі));
}
```

- Строка 1. На вход два текста файла: до сбора и после. Третий аргумент — список полей, которые не считаются.
- Строки 2–3. Нового файла нет — изменения нет. Старого не было — изменение есть, файл нужно выложить.
- Строки 4–8. Пробуем разобрать оба текста как JSON. `try` работает как в Python.
- Строки 9–10. Если JSON битый, сравниваем тексты как есть. Молчаливое «нет» спрятало бы сломанный файл.
- Строка 11. Убираем летучие поля функцией `без` и сравниваем строки. Разные — значит изменилось по сути.

Зачем: деплой должен идти только при смене цен. Метки `updated` и `collectedAt` меняются всегда и не в счёт.
