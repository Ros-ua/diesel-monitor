## Главное за 1 минуту

1. **Публикация уже работает без App Review.** Последние посты: карусель и сторис 25.09,
   Reels 27.09 (файлы `public/data/ig-*.json`). Причина: Meta даёт «Standard Access»
   (базовый доступ) бесплатно и без проверки, если приложение работает **только со своим**
   аккаунтом (у аккаунта есть роль в приложении). Наш случай ровно такой.
2. **App Review нужен для «Advanced Access»** (расширенного доступа) — когда приложением
   пользуются чужие аккаунты. Для автопубликации в @diesel.monitor.ua он формально **не обязателен**.
3. Зачем тогда подавать? Варианты (решение за владельцем) — см. раздел «Спорное»
   в [05-sources-and-open-questions.md](05-sources-and-open-questions.md):
   - **А.** Не подавать публикацию вообще, подавать только мост (комментарии/директ) — как в `docs/APP_REVIEW.md`.
   - **Б.** Подать публикацию вместе с мостом одним пакетом «про запас» (больше видео, больше риск отказа).
   - **В.** Подать только публикацию — если Meta в дашборде прямо требует ревью (например, показывает
     предупреждение про Development mode). Тогда всё в этой папке готово к использованию.
4. Для любого Advanced Access Meta требует **Business Verification** (подтверждение бизнеса документами).
   Если нет ФОП/юрлица — это вероятный блокер.

## Что нужно разрешение-минимум для публикации

- `instagram_business_basic` — узнать ID своего аккаунта (обязательная база для всех).
- `instagram_business_content_publish` — создать и опубликовать пост/карусель/сторис/Reels.

Подробности — в [01-permissions.md](01-permissions.md).
